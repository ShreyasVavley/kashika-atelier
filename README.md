# ⚜ KASHIKA • The Royal Silk Handloom Atelier

**House of Kashika** is an ultra-luxury digital handloom saree atelier engineered for royal Banarasi and Kanjivaram silk connoisseurs. 

Built around **one singular master Kadwa design** (*The Rajkumari Mayil Jangla*) transformed across **five sacred heritage colorways**, featuring 60 FPS real-time Zari light sheen physics, native Web Audio Tanpura resonance, a Master Karigar Provenance Ledger, an interactive 3-Piece Bridal Trousseau Velvet Trunk builder, and an expansive **High-Fashion Showcase Suite** inspired by physical boutique rituals and temple architecture.

---

## 🏛️ Brand Heritage & Design System
* **Aesthetic Direction:** Royal Indian Haute Couture (Sabyasachi / Raw Mango / Ekaya Banaras / NOOLAM Showcase).
* **Palette:** Pure Ivory Silk & Royal Alabaster (`#FFFFFF`, `#FAF7F2`), Deep Banarasi Vermilion (`#781224`, `#7A1C28`), Royal Court Indigo (`#0D1D36`), and 24K Burnished Temple Gold (`#C59B27`, `#D4AF37`).
* **Typography:** *Cormorant Garamond*, *Cinzel Decorative*, and *Montserrat*.

## 🗺️ Architectural Highlights & Interactive Showcase

* **The Atelier (Home)** (`#/`): Grand editorial hero, philosophy of the singular design, 5-shade photo lookbook cards, and real wedding patron gallery.
* **The Infinite Royal Marquee Ticker**: Seamless looping ribbon with 24K gold diamond glyphs (`◆`) broadcasting atelier features.
* **Six Moods Archive** (`#/moods`): 6 South Indian temple-arch (Gopuram) windows topped with brass Kalasam finials, lifting and glowing on hover.
* **The Rack (`#/rack`)**: Photorealistic physical clothes rail on a polished chrome rod with wooden hangers.
  * Live inventory category filter chips (*All pieces*, *Silk Sarees*, *Half Sarees*, *Full-Sleeve Blouses*, *Half-Sleeve Blouses*, *Checked Sarees*, *Zari & Brocade*).
  * **Hanger-Lift Inspection Modal**: Lifts the hanger off the rod into the center while blurring the background rail.
  * **Front / Back Toggle**: Switch views to inspect blouse embroidery back-neck or saree pallu.
  * **Sizing Suite**: Instant size selection chips (`34`–`42` / Free Size) with live bag addition.
* **Try the Look (`#/looks`)**: 8 complete looks, styled head to toe.
  * **Depth-of-Field Stage Carousel**: Center model in sharp focus; flanking models scaled down and blurred.
  * **"In this look" Ensemble Panel**: 6 coordinated pieces (Saree, Blouse, Choker, Jhumkas, Ottiyanam/Waistbelt, Bangles).
  * **10% Bundle Discount**: Automatic package discount calculation with single-click *"Add Full Look to Bag"* and gold confetti.
* **Pick a Silk (`#/picks`)**: 3D convex fanned card arc with oversized condensed titles behind cut-out models and cursor-tracking 3D tilt perspective physics.
* **The Muse Film & Reels (`#/muse`)**:
  * 16:9 brand film framed in fine gold borders with architectural corner brackets, sound toggle, and flanking dual vertical photo streamers continuously scrolling in opposite directions.
  * 3D curved arc video reels stream with fabric badges, location tags (*"The bride's chamber"*, *"Studio, Varanasi red"*), and progress scrubbers.
* **The Masterpiece Collection** (`#/collection`): Dedicated studio showcasing 1 design across 5 heritage colorways with 3 view modes (*Model Drape*, *Zari Shimmer Physics*, *Macro Zoom*).
* **The Craft & Karigar** (`#/craft`): 4-Stage Photo Journal of Varanasi pit loom weavers, Silk Mark India verification, and Kadwa vs Powerloom transparency guide.
* **Bridal Trousseau Trunk** (`#/trousseau`): 3-piece heirloom velvet trunk curator (*Muhurtham*, *Reception*, *Sangeet*) with live 15% bridal courtesy discount and customizable 24K engraved brass monogram nameplate.
* **Private Salon** (`#/salon`): Reservation suite for Bengaluru Flagship (*14 Lavelle Road*) & Varanasi Sanctuary, plus instant 1-on-1 Virtual HD Video Draping Consultation.

## 💻 Tech Stack
* **Framework:** React 19 + Vite 8
* **Styling:** Tailwind CSS 4 + Custom Royal Theme System
* **Animations & Physics:** Framer Motion + HTML5 Canvas
* **Icons:** Lucide React
* **Confetti:** Canvas Confetti

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server (http://localhost:5173)
npm run dev

# Build production bundle
npm run build
```
